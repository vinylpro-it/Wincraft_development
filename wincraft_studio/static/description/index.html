WinCraft Studio

Professional Window Design, Quotation & Fabrication — 100% Native Odoo 19

Overview

WinCraft Studio is a complete window fabrication management system built natively inside Odoo 19. It gives window manufacturers, dealers, and installers an interactive SVG canvas designer, live pricing engine, professional PDF quotes, cut-list generation, profile optimisation, and full fabrication tracking — all from a single Odoo module.

Manufacturing Quotation Fabrication Portal AI-Powered

Key Features

Interactive Designer

Drag-and-drop SVG canvas with snap-to-grid, undo/redo, component library, and elevation view. Design windows visually and see live pricing updates.

Live Pricing Engine

Automatic unit pricing based on material rates, glass type, hardware, add-ons, fabrication cost, and per-window margin percentage.

Professional PDF Reports

QWeb quote PDF with configurable tax, cut-list PDF with per-window dimensions, profile order sheets, and window fabrication labels.

Profile Optimiser

First-fit-decreasing bin-packing algorithm minimises aluminium bar waste. Visual bar diagrams show cutting patterns and utilisation.

AI Configuration Assistant

Describe windows in plain English — the AI parses specifications into structured configurations. Powered by Anthropic Claude with regex fallback.

Customer Portal

Branded portal with project list, detailed quote view, online acceptance, revision requests, and PDF download.

Dealer Network

Manage dealers with commission tracking, territory assignment, and performance analytics with stat buttons.

Analytics Dashboard

Pivot, graph, and list views for project analytics. Track revenue, window counts, material usage, and fabrication progress.

QR Fabrication Tracking

Generate QR codes per window. Fabricators scan to mark windows complete. Real-time status updates on the project.

WhatsApp Sharing

One-click quote sharing via WhatsApp with portal link. Pre-formatted message with project summary and total.

Quote Versioning

Automatic version control for quotes. Track revision history with chatter messages. Quick-quote wizard for rapid estimates.

Multi-Role Access

Four security roles: Admin, Sales, Fabricator, Viewer. Record rules and group-based menu visibility.
