# WinCraft Studio — Installation Notes

## Required

| Package               | Version     | Purpose                    |
|-----------------------|-------------|----------------------------|
| Odoo 19 (CE or EE)    | 19.0+       | Framework                  |

## Optional Python Packages

| Package               | Install command          | Purpose              |
|-----------------------|--------------------------|----------------------|
| python-qrcode + Pillow| `pip install qrcode[pil]`| QR codes on projects |

> If `qrcode` is not installed the module works normally —
> the QR Code tab simply shows a warning banner.
